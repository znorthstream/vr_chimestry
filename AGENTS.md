# AGENTS.md

Если ты агент (или разработчик), работающий с этим репозиторием — **начни с
[`PROJECT.md`](PROJECT.md)**. Там:

- карта всех файлов и за что они отвечают;
- как устроена архитектура (события, химический движок, XR, уроки);
- как собрать сцену и APK (меню `ChemLab` в Unity, детали в `docs/BUILD_APK.md`);
- как добавлять вещества/реакции/уроки **данными** (JSON), не меняя ядро;
- правила разработки (маленькие вехи, коммиты, объяснение ошибок, сцена только из кода).

Кратко — три главных правила:

1. **Сцена генерируется кодом** (`ChemLab → Setup → 2`), руками её не правим — правим
   `Assets/Editor/SceneBuilder.cs` / `LabFactory.cs`.
2. **Контент — в JSON** (`Assets/Chemistry/Data`, `Assets/Lessons`), не в C#.
3. **Вехи маленькие**: после каждого изменения — компиляция в Unity + APK + проверка на
   PICO 4 Ultra, коммит и push.
