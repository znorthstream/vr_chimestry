# Virtual Chemistry Lab — VR-химическая лаборатория для PICO 4 Ultra

Образовательное VR-приложение: интерактивная виртуальная химическая лаборатория, в которой
пользователь **физически** выполняет эксперименты контроллерами — берёт посуду, переливает
жидкости, смешивает реагенты, измеряет pH, массу и температуру, получает объяснения реакций
и оценку за работу.

- **Платформа:** PICO 4 Ultra (standalone, без ПК)
- **Стек:** Unity 6 LTS · C# · Android ARM64 (IL2CPP) · OpenXR · PICO Unity Integration SDK · XR Interaction Toolkit 3 · Input System · URP

## Быстрый старт (кратко)

1. Установите **Unity 6 LTS (6000.3+)** с модулем **Android Build Support** (OpenJDK + Android SDK/NDK).
2. Откройте проект в Unity. Дождитесь импорта пакетов.
3. Меню **ChemLab → Setup → 0. Install/Update Packages** (если есть проблемы с пакетами).
4. Меню **ChemLab → Setup → 1. Apply Project Settings** (Android, ARM64, IL2CPP, OpenXR, URP). Перезапустите Unity, если попросило.
5. Меню **ChemLab → Setup → 2. Build Laboratory Scene** — сцена собирается автоматически.
6. Меню **ChemLab → Build → Build Android APK** → `Builds/VirtualChemistryLab.apk`.
7. На шлеме включите режим разработчика (7 тапов по «Версия ПО» → «Отладка по USB») и выполните `adb install -r Builds/VirtualChemistryLab.apk`.

Подробно, со скриншот-подсказками и траблшутингом — в [`docs/BUILD_APK.md`](docs/BUILD_APK.md).

## Что уже работает (Milestone 1 — вертикальный срез)

- Взятие/перенос предметов контроллерами (Grip), нажатие кнопок лучом (триггер)
- Переливание наклоном сосуда, пипетка (набор/выливание триггером)
- Стакан, пробирка, стаканчик, весы, pH-метр с электродом, термометр
- 12 веществ, 4 химические реакции (растворение, нейтрализация с нагревом,
  осаждение Cu(OH)₂ и растворение осадка кислотой), индикаторы с цветом по pH
- Урок 1 «Знакомство с лабораторией» и Урок 2 «Нейтрализация кислоты» —
  теория → задания с автопроверкой → тест → оценка (точность/безопасность/методика)
- Система безопасности с объяснением ошибок (разбитая посуда, пролив, слив в раковину, перелив)
- Свободная лаборатория, лабораторный журнал, сохранение прогресса (JSON)
- Виртуальный планшет: уроки, подсказки (3 уровня), результаты, журнал, справка

## Структура репозитория

```text
Assets/
  Chemistry/Data/   JSON: вещества и реакции (данные отдельно от кода)
  Lessons/          JSON: уроки
  Editor/           Генерация сцены/настроек/APK (меню ChemLab)
  Scripts/          Runtime-код: Core, Chemistry, Equipment, Lessons, Safety, Save, UI
  Settings/         Input actions, URP-ассеты (создаются Setup-ом)
  Prefabs/          Префабы оборудования (генерируются билдером сцены)
  Scenes/           LaboratoryScene (генерируется билдером сцены)
docs/               Инструкции (сборка APK и т.д.)
```

## Правило разработки

Проект развивается **маленькими вехами**: каждая веха компилируется и даёт рабочий APK.
Не добавлять новые приборы/реакции до стабилизации текущего вертикального среза.
Полный план фаз — в [`PROJECT.md`](PROJECT.md).
